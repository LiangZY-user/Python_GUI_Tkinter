## Canvas.py 运行报错排查与修复
- 现象：在 VS Code 里运行 Canvas.py 报错。
- 定位：代码逻辑本身没问题；用 `C:\Python314\python.exe`（Python 3.14.10 / Tk 9.0，带 tkinter）在本文件目录下可正常启动。
- 根因：`tk.PhotoImage(file=r".\image\pic.gif")` 用的是相对当前工作目录的路径。只要 VS Code 的工作目录不是 `Python_GUI_Tkinter`（例如打开了上层 `D:\VsCodeProject`、或用 F5/Code Runner 启动），就抛 `_tkinter.TclError: couldn't open ".\image\pic.gif": no such file or directory`。
- 修复：改为基于 `__file__` 计算绝对路径 `BASE_DIR / image / pic.gif`，已验证在上层目录与本目录下启动均无报错。
- 环境约定（重要）：本机可用且带 tkinter 的解释器是 `C:\Python314\python.exe`（3.14.10, Tk 9.0），已在用户/系统 PATH 中。`C:\Users\User\.workbuddy\binaries\python\versions\3.13.12\python.exe` 没有 tkinter（`import tkinter` → ModuleNotFoundError），不要用它跑 GUI 脚本。
